# Code of Conduct

## Nuestro compromiso

Queremos que este espacio sea útil y respetuoso para cualquier persona interesada en Claude Code y en mejorar la calidad del software generado con IA, sin importar experiencia, origen, idioma o afiliación.

## Comportamiento esperado

- Lenguaje profesional y constructivo.
- Feedback orientado al código, no a la persona.
- Aceptar críticas razonadas con humildad.
- Reconocer el trabajo ajeno.
- Priorizar lo que beneficia al colectivo sobre la preferencia personal.

## Comportamiento inaceptable

- Acoso, insultos, lenguaje discriminatorio.
- Ataques personales o políticos.
- Doxing o publicación de información privada ajena.
- Spam, auto-promoción fuera de contexto, cadenas.

## Aplicación

Las infracciones se reportan a [contacto@proportione.com](mailto:contacto@proportione.com). El equipo responde en 48 horas laborables.

Medidas proporcionales a la gravedad:

1. Aviso privado.
2. Aviso público en el hilo afectado.
3. Suspensión temporal de participación.
4. Expulsión permanente del repositorio.

## Alcance

Aplica en Issues, Pull Requests, Discussions, commits, y cualquier espacio oficial del proyecto (incluidos canales externos donde se represente a Proportione).

## Adaptado de

Este código está inspirado en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), ajustado al tono y las necesidades de este proyecto.
